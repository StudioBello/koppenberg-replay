# Koppenberg Replay

Volg élke renner van de Koppenbergcross, niet alleen de leider. Een gratis replay van de koers op het echte parcours, voor de fans van élke crosser.

Een project van [Studio Bello](https://studiobello.be).

- `index.html` – de replay (werkt volledig in de browser, geen account nodig)
- `race.json` – de racedata: uitslag, tussenstanden uit liveverslaggeving en bronnen
- Data per koers is gelabeld als *officieel*, *gereconstrueerd* of *geschat*.
